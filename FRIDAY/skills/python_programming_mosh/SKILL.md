# python_programming_mosh

## Purpose
To guide users through the process of installing and setting up Python on a computer, and to introduce them to the basics of Python programming, including downloading and installing Python, understanding the importance of adding Python to PATH, and setting up a code editor like PyCharm.

## Execution Steps
1. **Download Python**:
   - Open your web browser and navigate to <https://python.org>.
   - Click on **Downloads**.
   - Select the latest version of Python (as of the tutorial date, it was 3.7.2).
   - For Windows: Double-click the downloaded installer to install Python 3. Make sure to check the box that says **Add Python to PATH**.
   - For Mac: Use the installer provided and follow the on-screen instructions, including accepting the license agreement and installing Python 3.

2. **Install PyCharm**:
   - Navigate to <https://www.jetbrains.com/pycharm/>.
   - Download and install PyCharm, following the on-screen instructions.

3. **Verify Installation**:
   - Open PyCharm and verify that Python 3 is installed correctly.
   - Try running a simple Python program to ensure everything is set up properly.

## Constraints & Verifications
- Ensure that the latest version of Python is downloaded (as of the tutorial date, Python 3.7.2).
- Verify that Python 3 is added to the PATH environment variable for Windows to ensure it can be used from the command line.
- Confirm that PyCharm is installed and functioning correctly.
- Verify that a simple Python program runs successfully within PyCharm.
